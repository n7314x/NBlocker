# YouTube features

## Milestone 1

- persistent website session and native browser navigation;
- hide Shorts tabs/buttons and Shorts shelves;
- optional `/shorts/` route blocking;
- optional Home and related-recommendation filtering;
- disable the HTML media autoplay attribute and supported autoplay controls;
- best-effort prevention of clicks into the next Short after a Short is open;
- optional search-route blocking and semantic search-suggestion hiding;
- independently hide comments;
- grayscale and direct-to-Subscriptions configuration hooks;
- grouped settings for Shorts, Home, Recommendations, Playback, Search,
  Subscriptions, Comments, and Appearance.

## Planned

Allow-one shared Short and more exact player-state handling require fixture and
on-device validation. Thumbnail suppression is implemented as a conservative visual
rule and may need selector updates as YouTube changes.
