# Instagram integration

Instagram runs at `https://www.instagram.com/` in a persistent `WKWebView`. Swift
classifies requested routes and can cancel disallowed Reel navigation before load.
Bundled rule resources then remove configured entry points and distracting modules.

Selectors are best-effort and expected to evolve. Each resource is independent and
failure-safe. Login, cookies, password entry, and direct-message content are owned by
Instagram and WebKit, not parsed or stored by NBlocker.
