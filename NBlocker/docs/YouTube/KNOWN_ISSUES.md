# YouTube known issues

- Mobile YouTube is a single-page app and may rename custom elements over time.
- JavaScript cannot guarantee background audio or Picture in Picture support.
- Autoplay prevention is best-effort and must not interrupt a user-initiated video.
- Next-Short link clicks are intercepted best-effort; player gestures need fixture
  and on-device validation before stronger claims.
- Localized accessible labels need fixture coverage beyond English.
